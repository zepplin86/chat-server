# 채팅 서버

대규모 채팅 서버를 가장 단순한 형태에서 시작해 한 단계씩 키워 가는 프로젝트.

- 진행 원칙과 단계 계획, git 작업 방식: [CLAUDE.md](CLAUDE.md)
- 완성형 참고 구현: `result` 브랜치 (`git switch result`)

## 지금 상태: 1단계

서버 한 대, 방 하나. 대화는 서버의 메모리에만 있다.

```
 브라우저 ──┐
 브라우저 ──┼── WebSocket ──► 서버 1개 (대화를 메모리에 보관)
 브라우저 ──┘
```

WebSocket은 브라우저와 서버가 한 번 연결하면 끊지 않고 계속 주고받는 통신 방식이다.
일반 웹 요청은 브라우저가 물어야만 서버가 답하지만, WebSocket은 서버가 먼저 보낼 수 있다.
그래서 다른 사람이 쓴 메시지를 바로 받을 수 있다.

### 실행

```bash
cargo run
```

브라우저에서 `http://localhost:8080` 을 탭 두 개로 열고, 서로 다른 이름으로 들어가 대화한다.
끝낼 때는 터미널에서 Ctrl-C.

### 코드

| 파일 | 내용 |
|---|---|
| `src/main.rs` | 서버 전체. 약 120줄 |
| `static/index.html` | 테스트 화면 |

### 해 볼 것

1. 탭 두 개로 대화해 본다.
2. 세 번째 탭으로 늦게 들어가 본다. 지난 대화가 보인다.
3. 서버를 Ctrl-C 로 끄고 `cargo run` 으로 다시 켠 뒤 접속해 본다. **대화가 전부 사라져 있다.**

### 이 단계의 한계

- 서버를 끄면 대화가 사라진다. → 2단계에서 DB에 저장한다.
- 방이 하나뿐이다.
- 이름을 아무나 아무렇게나 쓸 수 있다. 로그인이 없다.
- 연결이 끊기면 자동으로 다시 붙지 않는다.
