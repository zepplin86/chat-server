# 채팅 서버

대규모 채팅 서버를 가장 단순한 형태에서 시작해 한 단계씩 키워 가는 프로젝트.

- 진행 원칙과 단계 계획, git 작업 방식: [CLAUDE.md](CLAUDE.md)
- 완성형 참고 구현: `result` 브랜치 (`git switch result`)
- 단계별 사고 과정 (왜 그렇게 했고, 무엇을 일부러 하지 않았는지): [docs/](docs/)

## 지금 상태

4단계(`v0.4.0`)까지 끝났다. 서버들 사이에서 NATS 가 메시지를 날라 준다.
어느 서버에 붙었든 같은 방 사람끼리 실시간으로 대화가 된다. (사고 과정: [docs/04-nats.md](docs/04-nats.md))

```
                              ┌──▶ 서버 1 (8081) ─┐
브라우저들 ──▶ 로드밸런서 ────┤       ▲▼          ├──▶ PostgreSQL
              (8080)          │      NATS         │
                              │       ▲▼          │
                              └──▶ 서버 2 (8082) ─┘
```

## 실행

```bash
docker compose up -d   # PostgreSQL, 로드밸런서, NATS 켜기 (처음 한 번)
cargo run              # 터미널 1: 채팅 서버 (8081)
PORT=8082 cargo run    # 터미널 2: 채팅 서버 한 대 더 (8082)
```

브라우저로 http://localhost:8080 을 열고 이름과 비밀번호를 넣고 방을 고르면 대화할 수 있다.
처음 쓰는 이름이면 그 비밀번호로 계정이 만들어진다.

서버는 한 대만 띄워도 된다. 로드밸런서가 켜져 있는 쪽으로 보낸다.
서버를 껐다(Ctrl+C) 다시 켜도 지난 대화가 남아 있다.
